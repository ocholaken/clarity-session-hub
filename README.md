# Am Security

Am Security is a security management system for connecting users with counselors, booking protected sessions, managing resources, and administering appointments and session records.

## Getting started

Requirements: Node.js and npm.

Install dependencies and start the development server:

```sh
npm install
npm run dev
```

## Technology

The application is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Supabase

## Available scripts

- `npm run dev` starts the Vite development server.
- `npm run build` creates a production build.
- `npm run lint` checks the source code with ESLint.
- `npm run preview` serves the production build locally.
